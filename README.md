# AI Resume Analyzer

AI-powered resume analyzer with ATS scoring and personalized feedback.

## Features

- Resume upload
- AI-powered resume analysis
- ATS score
- Job description matching
- Skill gap analysis
- Personalized improvement suggestions

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- AI/LLM API
